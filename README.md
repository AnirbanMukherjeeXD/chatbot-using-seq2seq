# Chatbot using Seq2Seq with LSTM

This repository contains a simple chatbot implementation using a **Sequence-to-Sequence (Seq2Seq)** model built with **TensorFlow's Keras API**. The chatbot is trained on a small dummy dataset for demonstration purposes.

## Model

- Encoder–Decoder architecture using **LSTM** layers
- Implemented with `tf.keras`
- Tokenization, padding, and sequence generation handled in notebook

## Main Notebook

- `Chatbot_Seq2Seq_LSTM.ipynb` – Complete workflow for building, training, and testing the chatbot

## Dataset

- `chatbotText-small.csv` – A small conversational dataset used to train and test the model

## Requirements

- TensorFlow (2.x)
- NumPy
- Pandas
